COST SHEET PRO V2 — LOCAL APPLICATION

FEATURES
- Premium Streamlit interface
- Company/product/period setup
- Editable cost components
- Direct material, labour, expenses and overheads
- Opening/closing WIP and finished-goods adjustments
- Prime Cost, Works Cost, Cost of Production and Cost of Sales
- Target profit and GST/tax calculation
- Cost per unit, selling price per unit and profit per unit
- Cost-structure dashboard
- One-click professional Excel export

RUN LOCALLY
1. Install Python 3.10+
2. Open terminal in this folder
3. pip install -r requirements.txt
4. streamlit run app.py
5. Open the localhost URL shown in terminal.
